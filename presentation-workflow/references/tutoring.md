# Japanese study-abroad tutoring lessons

Treat the deck as a teaching outline and conversation prompt. Plan material for a flexible 1–2 hour lesson, with enough substantive discussion and exercises to use the available time; unfinished material can continue next time. Pages should invite the student to explain their thinking, ask questions, and make decisions, rather than only display a completed answer.

Normally include a brief check on school choices and professor outreach, a review of this week's tasks, and a rough plan for next week. Organize the main work around the student's real application deadlines and current bottlenecks, such as research-proposal feedback and discussion. Check the relevant school's current official requirements and dates before presenting them as facts; record which application year and program they apply to.

Use the same page-map and page-blueprint workflow as the main skill. For each activity, note the prompt, expected student contribution, materials needed, and an approximate time range. The time plan should remain adaptable to the student's questions and progress.
